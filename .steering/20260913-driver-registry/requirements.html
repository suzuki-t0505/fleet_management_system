.steering / 20260913-driver-registry

要求内容：運転者台帳

対象機能: F-3 運転者台帳管理（functional-design.md 4.3・6.2）

1. 背景

運行日報（F-4）は「誰が運転したか」を必須項目とするため、運転者を選択肢として提供する台帳が必要になる。 また、免許証の有効期限は期限アラート（F-5）の監視対象であり、車両の期限と同じ仕組みで扱う。

車両台帳（20260913-vehicle-registry）で作った スコープ付き Context・共通コンポーネント・監査ログの型をそのまま適用する。

2. 目的

  • 拠点ごとに分散している運転者情報を、全社単一の台帳に統合する
  • 運行日報で運転者を選択できる状態にする（F-4 の前提を満たす）
  • 免許証の有効期限をデータとして保持し、期限アラート（F-5）が参照できる状態にする
  • ログインアカウント（users）と運転者台帳（drivers）を紐付け、日報の入力者と運転者を自動で対応づけられるようにする

3. 対象範囲

#優先度要求
R-1P0 運転者の登録・編集。必須項目（氏名・氏名かな・所属拠点・雇用区分・入社年月日・免許証番号・免許種類・免許証有効期限）と任意項目（運転者コード・退職年月日・備考）
R-2P0 バリデーション（functional-design.md 6.2 の V-6〜V-8）。免許証有効期限が過去日の場合は警告を表示（保存は可能）、1運転者につきアカウントは1つまで、退職者は選択肢から除外
R-3P0 運転者一覧。拠点・雇用区分での絞り込み、氏名・氏名かなの部分一致検索、ページネーション。免許証有効期限の残日数を表示する
R-4P0 運転者詳細。基本情報・免許情報・紐付いたアカウントを表示する。運行日報と事故ヒヤリの履歴は枠のみ
R-5P0 アカウントとの紐付け。自拠点のユーザーから選択して紐付けでき、既に他の運転者に紐付いたアカウントは選択肢に出さない
R-6P0 Accounts.Scope への driver_id の反映。ログインユーザーに運転者が紐付いている場合、スコープから参照できるようにする（F-4 で使用）
R-7P0 拠点スコープの徹底。運行管理者は自拠点の運転者のみ参照・編集でき、他拠点のURLに直接アクセスすると404になる
R-8P0 退職の扱い。雇用区分を「退職」にすると一覧の既定表示から除外される。記録は保持する
R-9P0 監査ログ。運転者の作成・更新を記録する
R-10P1 ナビゲーションの有効化。サイドバーの「運転者」を有効にする（運行管理者・管理者のみ）

4. 対象外

  • 一般利用者向けの画面 — 権限マトリクス（functional-design.md 2.2）で運転者台帳の参照は運行管理者・管理者のみと定義しているため
  • 免許証の画像添付 — GCPが未手配のため、車両の添付ファイルとまとめて別作業にする
  • 免許証期限のアラート通知（F-5） — 期限の保持までを行い、監視・通知は別作業
  • 詳細画面の履歴表示 — 運行日報・事故ヒヤリのテーブルが未作成のため枠のみ
  • 運転者の一括取り込み（CSVインポート） — 現行Excelからの移行方法は運用と合わせて別途検討する

5. 完了条件

#条件
C-1make check がすべて成功する
C-2運行管理者が自拠点の運転者を登録・編集でき、一覧に反映される
C-3運行管理者が他拠点の運転者の詳細・編集URLに直接アクセスすると404になる
C-4免許証有効期限が近い運転者に残日数バッジが表示される（車両の期限と同じ配色）
C-5既に他の運転者に紐付いたアカウントは、紐付けの選択肢に表示されない
C-6雇用区分を「退職」にすると一覧の既定表示から消える
C-7アカウントを紐付けた利用者でログインすると、current_scope.driver_id に値が入る
C-8一般利用者が /management/drivers にアクセスするとダッシュボードへ差し戻される
C-9一覧・詳細・フォームが 375px で横スクロールせずに操作できる
C-10運転者の作成・更新が audit_logs に記録される

6. 前提・制約

  • 車両台帳で作った共通コンポーネント（data_table / search_bar / pagination / deadline_badge / section_card）を再利用する。2つ目の台帳で初めて汎用化の要否を判断する
  • Context 関数は第1引数に Accounts.Scope を取り、拠点の絞り込みをクエリ層で行う
  • 物理削除を実装しない
  • 個人情報（免許証番号）を扱うため、ログに出力しない（development-guidelines.md 6.7）
  • seeds に開発用の運転者データを追加する
