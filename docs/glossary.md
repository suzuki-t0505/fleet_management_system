# ユビキタス言語定義 (Glossary)

## 0. 本書の位置づけ

- **何を書くか**: 業務用語とコード上の表記の対応。チーム内・ドキュメント・コード・UI で**同じものを同じ言葉で呼ぶ**ための辞書
- **使い方**:
  - 実装時、テーブル名・カラム名・関数名・変数名は本書の英語表記を使う
  - UI の表示文言・エラーメッセージは本書の日本語表記を使う
  - 本書にない業務用語が出てきたら、実装前に本書へ追加する

---

## 1. 用語の使い分け（間違えやすいもの）

実装・設計で混同が起きやすい対を先に定義する。

| 対 | 違い |
|----|------|
| **利用者 (user)** ↔ **運転者 (driver)** | `user` は**ログインアカウント**。`driver` は**運転者台帳のレコード**。運転者は必ずしもアカウントを持たない（アカウントなしで台帳登録できる）。両者は `drivers.user_id` で任意に紐付く |
| **管理者 (admin)** ↔ **運行管理者 (manager)** | `admin` は本社のシステム管理者で全拠点＋ユーザー管理が可能。`manager` は拠点の運行管理者で自拠点の台帳・承認のみ。「管理者」は `admin` のみを指し、`manager` を含めない |
| **車両番号 (plate_number)** ↔ **車台番号 (vin)** | `plate_number` はナンバープレートの表示（例: 品川100あ12-34）。`vin` は車体に刻印された固有番号 |
| **走行距離 (distance_km)** ↔ **オドメーター (odometer)** | `distance_km` は1回の運行での走行距離（差分）。`odometer` は積算距離計の値（絶対値） |
| **車検 (inspection)** ↔ **法定点検 (periodic_3m / periodic_12m)** | `inspection` は継続検査（車検）。`periodic_*` は定期点検整備。どちらも `maintenances.category` の値だが別物 |
| **事故 (incident: injury / property / single)** ↔ **ヒヤリハット (near_miss)** | どちらも `incidents` テーブルに入るが `category` で区別する。「事故記録」と言う場合はヒヤリハットを含まない |
| **提出 (submit)** ↔ **承認 (approve)** | `submit` は運転者が日報を出す操作。`approve` は運行管理者が内容を認める操作。「提出済み」は未承認の状態 |
| **拠点 (office)** ↔ **本社** | `office` は営業所を含むすべての拠点レコード。本社も `offices` の1レコードとして登録する。専用のフラグは持たない |
| **無効化 (active = false)** ↔ **削除 (delete)** | 本システムに物理削除はない。「削除」という語を UI・コードで使わず、「無効化」「廃車」「退職」と言う |

## 2. 組織・アカウント

| 日本語 | 英語 / コード表記 | 定義 |
|-------|-----------------|------|
| 拠点 | `office` / `offices` | 本社・営業所などの組織単位。データの分離境界になる |
| 拠点コード | `code` | 拠点を識別する社内コード。全社で一意 |
| 利用者 / ユーザー | `user` / `users` | ログインアカウント。必ず1つの拠点に所属する |
| ロール | `role` | 権限区分。`admin` / `manager` / `member` の3種 |
| 管理者 | `admin` | 本社のシステム管理者。全拠点の参照・編集とユーザー管理が可能 |
| 運行管理者 | `manager` | 拠点の運行管理者。自拠点の台帳管理と日報・改善報告の承認が可能 |
| 一般利用者 | `member` | 運転者。自分に紐づく記録の作成・参照のみ |
| スコープ | `scope` / `Accounts.Scope` | ログインユーザーの権限とデータ範囲を表す構造体。Context 関数の第1引数に必ず渡す |
| 無効化 | `active = false` | アカウント・拠点を使用停止にすること。過去の記録は残る |

## 3. 車両

| 日本語 | 英語 / コード表記 | 定義 |
|-------|-----------------|------|
| 車両 | `vehicle` / `vehicles` | 管理対象の車両1台 |
| 車両台帳 | vehicle registry | 車両の基本情報・期限情報を管理する台帳。画面名として使う |
| 車両番号 | `plate_number` | ナンバープレートの表示。全社で一意 |
| 車台番号 | `vin` | 車体固有の識別番号 |
| 車種区分 | `vehicle_class` | `large`(大型) / `medium`(中型) / `semi_medium`(準中型) / `ordinary`(普通) / `light`(軽) / `other`(その他) |
| 車両ステータス | `status` | `active`(稼働中) / `maintenance`(整備中) / `idle`(休車) / `scrapped`(廃車) |
| 初度登録年月 | `first_registered_on` | 車両が最初に登録された年月 |
| 最大積載量 | `capacity_kg` | 積載可能な最大重量（kg） |
| 車両総重量 | `gross_weight_kg` | 車両重量＋最大積載量＋乗車定員重量（kg） |
| 燃料種別 | `fuel_type` | `diesel` / `gasoline` / `hybrid` / `ev` / `other` |
| 所有区分 | `ownership` | `owned`(自社所有) / `lease`(リース) |
| 車検満了日 | `inspection_expires_on` | 継続検査の有効期限 |
| 自賠責保険満了日 | `liability_insurance_expires_on` | 自動車損害賠償責任保険の満了日 |
| 任意保険満了日 | `voluntary_insurance_expires_on` | 任意加入の自動車保険の満了日 |
| 最終オドメーター | `latest_odometer` | 当該車両で最後に記録された積算距離。日報の承認時に更新される |
| 休車 | `idle` | 保有しているが運用していない状態。廃車ではない |
| 廃車 | `scrapped` | 保有を終えた状態。一覧のデフォルト表示から除外される |

## 4. 運転者

| 日本語 | 英語 / コード表記 | 定義 |
|-------|-----------------|------|
| 運転者 | `driver` / `drivers` | 運転業務に従事する人員の台帳レコード |
| 運転者台帳 | driver registry | 運転者の基本情報・免許情報を管理する台帳 |
| 運転者コード | `code` | 運転者を識別する社内コード。全社で一意 |
| 氏名かな | `name_kana` | 検索・並び替えに使うふりがな |
| 雇用区分 | `employment_type` | `full_time`(正社員) / `contract`(契約社員) / `part_time`(パート) / `other`(その他) / `retired`(退職) |

| 免許証有効期限 | `license_expires_on` | 運転免許証の有効期限。期限アラートの対象 |
| 退職 | `employment_type = retired` | 在籍を終えた状態。記録は保持され、選択肢から除外される |

## 5. 運行日報

| 日本語 | 英語 / コード表記 | 定義 |
|-------|-----------------|------|
| 運行日報 | `operation_report` / `operation_reports` | 1回の運行（出庫から帰庫まで）の記録 |
| 運行日 | `operation_date` | その運行を計上する日。出発日時の日付と一致するとは限らない |
| 出発日時 / 帰着日時 | `departed_at` / `returned_at` | 出庫・帰庫の日時。UTC で保存し JST で表示する |
| 出発時オドメーター | `start_odometer` | 出庫時の積算距離計の値 |
| 帰着時オドメーター | `end_odometer` | 帰庫時の積算距離計の値 |
| 走行距離 | `distance_km` | `end_odometer - start_odometer`。システムが算出し手入力させない |
| 主な行き先 | `destination` | 代表的な配送先・経由地 |
| 荷種 | `cargo_type` | 積載した貨物の種別 |
| 休憩時間 | `rest_minutes` | 運行中の休憩の合計（分） |
| 給油記録 | `refueling` / `refuelings` | 運行中の給油1回分の記録。日報に従属する子エンティティ |
| 給油量 | `liters` | 給油したリットル数 |
| 燃費 | fuel efficiency | 走行距離 ÷ 給油量（km/L）。集計画面でのみ算出する（保存しない） |
| 下書き | `draft` | 運転者が作成中で未提出の状態 |
| 提出済み | `submitted` | 運転者が提出し、運行管理者の確認待ちの状態 |
| 承認済み | `approved` | 運行管理者が内容を認めた状態。集計の対象になる |
| 差戻し | `rejected` | 運行管理者が修正を求めて返した状態。理由が必須 |
| 差戻し理由 | `rejected_reason` | 差戻し時に運行管理者が記入する修正依頼の内容 |

## 6. 点検・整備

| 日本語 | 英語 / コード表記 | 定義 |
|-------|-----------------|------|
| 点検整備記録 | `maintenance` / `maintenances` | 車両に対して実施した点検・整備・修理1件の記録 |

## 7. 事故・ヒヤリ

| 日本語 | 英語 / コード表記 | 定義 |
|-------|-----------------|------|
| 事故・ヒヤリ記録 | `incident` / `incidents` | 事故およびヒヤリハット1件の記録 |
| 人身事故 | `injury` | 人の死傷を伴う事故 |
| 物損事故 | `property` | 物の損壊のみの事故 |
| 車両単独 | `single` | 相手方のいない事故、および車両の不具合報告 |
| ヒヤリハット | `near_miss` | 事故には至らなかったが危険を感じた事象 |
| 車両不具合報告 | `category = single` | 運転者が気づいた異音・警告灯などの報告。運行管理者の未対応一覧に載る |
| 発生状況 | `description` | 何が起きたかの自由記述 |
| 直接原因 | `direct_cause` | その事象を直接引き起こした要因 |
| 背景要因 | `background_factor` | 直接原因の背後にある構造的な要因（体制・時間的制約など） |
| 改善策 | `countermeasure` | 再発防止のために実施する対策 |
| 改善報告 | countermeasure report | 原因分析と改善策をまとめて報告する一連の行為・画面名 |
| 実施責任者 | `countermeasure_owner` | 改善策の実施に責任を持つ人 |
| 報告済み | `reported` | 報告が登録され、分析が未着手の状態 |
| 原因分析中 | `analyzing` | 運行管理者が原因を分析している状態 |
| 改善報告済み | `countermeasure_reported` | 原因と改善策が登録され、承認待ちの状態 |
| 完了 | `closed` | 改善報告が承認された状態 |
| 全社共有 | `shared_company_wide` | ヒヤリハットを他拠点にも公開する設定。個人名は伏せて表示する |

## 8. 期限アラート

| 日本語 | 英語 / コード表記 | 定義 |
|-------|-----------------|------|
| 期限アラート | deadline alert | 車検・保険・点検・免許の期限が近づいたことを知らせる通知 |

| 通知ログ | `alert_notification` / `alert_notifications` | 通知の送信記録。重複送信の防止に使う |

## 10. 使わない表記

同じものを指す別表記を禁止し、揺れを防ぐ。

| 使わない | 使う | 理由 |
|---------|------|------|
| ドライバー | 運転者 | 台帳の正式名称に合わせる |
| 営業所 | 拠点 | 本社を含むため上位語を使う |
| 日報レポート / 運行記録簿 | 運行日報 | 正式名称に統一 |
| ヒヤリ / ニアミス | ヒヤリハット | 正式名称に統一 |
| 車検証の期限 / 車検期限 | 車検満了日 | データ項目名に合わせる |
| 走行メーター / 距離計 | オドメーター | データ項目名に合わせる |
| 削除する | 無効化する / 廃車にする / 退職にする | 物理削除が存在しないため |
| 承認者 = 管理者 | 承認者 = 運行管理者または管理者 | `manager` と `admin` を混同しない |
| ユーザー（運転者の意味で） | 運転者 | `user` と `driver` を混同しない |

## 11. 略記・単位

| 表記 | 意味 |
|------|------|
| JST | 日本標準時。表示に使う（保存は UTC） |
| km | 走行距離の単位。3桁区切りで表示（`1,234 km`） |
| L | 給油量の単位。小数第2位まで（`12.34 L`） |
| 円 | 金額の単位。税込・整数（`¥1,234`） |
| P0 / P1 / P2 | 優先度（必須 / 重要 / できれば）。[product-requirements.md](product-requirements.md) の定義に従う |
| V-n | 業務ルール・バリデーションの識別子。[functional-design.md](functional-design.md) 6章 |
| F-n | 機能の識別子。[product-requirements.md](product-requirements.md) / [functional-design.md](functional-design.md) |
